# Frost Sphere Security System

## Defensive Layers
The Frost Sphere employs multiple layers of security to protect itself from intruders. Understanding these layers will help you navigate the climactic scenes in Session 1.

### Layer 1: Cold Aura
The sphere emits an unnatural cold that intensifies as one gets closer:
- **100ft Radius:** 1d6 cold damage per minute
- **50ft Radius:** 2d6 cold damage per minute
- **The Frost Resistance Elixir** provides complete immunity to this cold damage
- Winter clothing or ordinary cold resistance provides no protection

### Layer 2: External Guards
Guards patrol the perimeter and protect the entrance:
- **Winter Wights (3-4):** Enhanced versions with coordinated tactics
- **Ice Guardians (2):** Elite constructs that guard the entrance
- The guards follow patrol patterns but will converge if they detect intruders

### Layer 3: Internal Security System
If the players enter the sphere and trigger the security system:
1. Control panel emits high-pitched tone
2. Blue light intensifies throughout sphere
3. Spectral image of the Frost Architect appears
4. Ice constructs begin forming throughout the sphere

## Disabling the Sphere
There are three methods to disable or destroy the sphere:

### Method 1: Direct Damage to Core
- Core is protected by barriers (AC 18, 50 HP)
- Must break through barriers to directly damage the core
- Once barriers are down, any damage to core will disrupt its function
- Fire damage is particularly effective (double damage)

### Method 2: Control Panel Override
- Requires three successful Arcana checks (DC 17)
- Each success allows manipulation of one system component
- Three components must be disabled in sequence:
  1. Rune power matrix
  2. Cold energy conduit
  3. Central core controller
- Failure on any check triggers immediate security response

### Method 3: Power Conduit Disruption
- Perception check (DC 15) to locate key conduits
- Four main conduits connect to cardinal points of sphere
- Disrupting three of four conduits weakens sphere significantly
- Can be done by physical damage or magical interference
- Each disrupted conduit reduces sphere's cold output by 25%

## Security Response Sequence
When security is triggered:

1. **Alert Phase (1 round)**
   - High-pitched tone sounds
   - Lights intensify
   - Spectral image appears

2. **Communication Phase (1 round)**
   - Frost Architect speaks in Primordial
   - If anyone understands Primordial: "...network disrupted... intruders detected... deploying guardians..."
   - If no one understands: The language sounds like cracking ice and howling wind

3. **Deployment Phase (1d4+1 rounds)**
   - Ice constructs begin forming from walls
   - 1 new Ice Scout forms each round
   - Players have limited time before being overwhelmed

4. **Sphere Collapse (optional)**
   - If core is damaged beyond 50% capacity, sphere begins collapsing
   - Players have 1d4 rounds to escape before full collapse
   - Collapse releases burst of cold energy (4d6 cold damage, 30ft radius)

## Player Decision Point
Players must quickly decide whether to:
1. Attempt to disable the sphere (higher risk, greater reward)
2. Retreat with gathered information (safer option)

## Information Gathered
Even if players retreat, they have valuable intelligence:
- Sphere's purpose (gathering cold energy)
- Network of spheres being deployed across the mountains
- Connection to the Frost Architect
- Potential methods to disable future spheres they encounter

## Running the Climax
- Keep track of time/rounds once security is triggered
- Create a sense of urgency as ice constructs form
- If players choose to disable the sphere, make the process dramatic
- If they choose to retreat, emphasize the valuable information they've obtained
- Either choice is valid and leads to Session 2

## Adjusting Difficulty
- For easier experience: Reduce number of forming constructs
- For harder experience: More rapidly forming constructs, or partially formed constructs attack immediately
- Adjust hit points of barriers protecting the core based on party size and level
