# NPCs Directory

This directory contains character sheets for Non-Player Characters (NPCs) in the Frost Architect Campaign.

## Organization

NPCs are organized into two categories:

- **allies/**: NPCs who are friendly or neutral toward the player characters
- **villains/**: NPCs who are antagonistic toward the player characters

Each NPC has its own markdown file with a standardized character sheet format.

## Naming Conventions

Files follow kebab-case naming convention:
- All lowercase
- Words separated by hyphens
- No underscores or spaces

Example: `frost-touched-merchant.md` instead of `Frost_Touched_Merchant.md`

## File Structure

Each NPC file should include the following sections:

1. **Header**: Name, type, alignment
2. **Statistics**: AC, HP, abilities, etc.
3. **Special Abilities**: Any unique traits or powers
4. **Actions**: Combat and non-combat actions
5. **Equipment**: Items carried or used
6. **Personality**: Character traits, motivations, etc.
7. **Information**: What the NPC knows or can share
8. **Description**: Physical appearance and notable features

## Using These NPCs

These NPCs can be used across multiple modules in the campaign. When incorporating an NPC into a specific module, reference their character sheet here rather than duplicating information.
